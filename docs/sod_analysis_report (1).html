Топ-5 рисков СФЕРА

  1. 1. ЗП-карта (S10/B2/X7) — формирование, начисление и выплата ЗП одним лицом. Критический K1
  2. 2. Приём/увольнение (S1–S3) — полный цикл HR-операций без разделения. Высокий K1
  3. 3. OKR → Бонусы (T1/X3) — оценка целей и начисление бонуса одним лицом. Высокий K1
  4. 4. РВД (S4/X5/S21) — назначение, изменение и подтверждение смен. Высокий K1
  5. 5. АТС (P1/X2) — полный цикл подбора: вакансия → оффер → приём. Высокий K2
